# eatongo Frontend Demo

Responsive app-style ideathon prototype with a role-selection entry screen and separate customer and vendor experiences. Customers enter through a camera-first outlet QR scanner. Vendors complete dummy authentication, identify their workplace, upload or edit a menu, receive an outlet QR, and then manage QR ordering, simulated payment verification, pickup tokens, live queues, pre-orders, loyalty rewards, menu operations, and analytics.

All data and transactions are simulated in the browser for the demo. A production implementation must add authenticated server APIs, database row-level security, gateway webhooks, idempotent payment and loyalty ledgers, and single-use token verification.

## Visual direction

The customer experience uses a phone-sized mobile-app shell, bold modular color blocks, tactile cards, expressive labels, and subtle motion for an energetic campus-food feel without becoming childish. The vendor experience uses a responsive dark dashboard with denser information, bright operational status accents, and the same shared brand colors.
